特点

托付出去的事，多半在你不看着的时候发生。下面八条说的是那时它怎么认人、记事、跟进、接着办，又在什么时候停下来问你。

认得出人，也分得清说法

你告诉过它的号码和邮箱，都记在这个人的档案里，他换哪种方式找你，它都认得出。他是你的什么人，只有你说了才算。陌生号码自称房东换了号，这个号码不会因此算作房东的；信里写着“以后发票都转给我”，没有你点头，它不会照做。

程序保证

记下的，都是你读得懂的文件

你随口说一句“周报以后发到工作邮箱”，下周它就照做。你的规矩、每个人的档案、没办完的事项，都是工作区里的普通文件，随时可以打开、修改。它记下一条规矩会告诉你，不对就用 /undo 撤回。

要等的事，交给它等

约一个大家都有空的时间，催一份迟迟不来的回复：一件事一条会话。对方一回，它醒来接着办；到时间还没回，它起草一条提醒，你同意才发；办不下去，它停下来问你，接着做还是到此为止。

程序保证

你还没想起来，它已经在办

提醒到点、邮件进来、交办的事有了回音，都会叫醒它。没事的时候它只是等着，不运行模型，也不花钱。接了邮箱或电话，它每晚把当天的往来整理成一屏简报。房东说热水器修好了，它会问你这件算不算办完，不替你关掉。

被打断了，从停下的地方接着办

每一步先记下，再去执行。断电、崩溃或者重启之后，它从最后一步接着办。一封信发到一半被打断，它不会悄悄重发，而是告诉你结果不明，由你决定。

程序保证

替你开口之前，先问你

它可以起草回信、安排时间、回复联系人，但每一句要发给别人的话，都先停下来等你同意，发出去的就是你看过的那一版。它向对方说明自己是你的 AI 助理，不冒充你。

程序保证

每件事都有出处

回答用到读过的网页或你工作区里的文件，链接就跟在那件事后面。你不必凭信任，点开就能核对。

用哪个模型、花多少，由你定

用你的 ChatGPT 订阅，或者 Anthropic、OpenAI、DeepSeek 的 API key，每条会话各选模型。一天花到 10 美元（可以改），它就不再自己启动新的事，只办你亲口交代的。

评测

有的事由程序保证，比如替你对外开口先问你、断了从停下处接着办，这些都有测试守着。有的事要靠模型判断：该记什么，该问什么，出处写没写对。这一类用真实的模型来测：改一处之前测一次，改完再测一次。世界、地址和号码都是编的，图里的每个点都是一次实测。

原则

Alfred 宁可少做，也要做准。加什么、删什么、改什么，都按下面四条取舍。

只为真实的问题
一项能力，从一个真实的例子和你感受得到的价值开始。“以后可能用得上”不算理由；不做也过得去的，就不做。
少概念，常删减
新概念要么替换掉一个旧的，要么解决一个已经发生的问题。每个阶段结束都逐项审计：没人用的、只为将来留着的，删掉或简化。
以测得的数为准
说一处变好了，要拿出改之前和改之后的数；小于噪声的差别，不算差别。测不准的，写明没把握。
失败看得见
一件事要么有结局，要么告诉你停在哪里。不静默吞掉错误，不停在半路。

安装

macOS 和 Linux，arm64 和 amd64。

curl -fsSL https://github.com/nowa/alfred/releases/latest/download/install.sh | sh

在终端里运行。脚本核对下载的包，把 alfred 和 alfred-telegram 装进 ~/.local/bin，再运行 alfred setup：一问一答完成设置，不用写配置文件。用 Hermes Agent 的，alfred setup 会提出把记忆、skill、定时任务、看板和对话搬过来。

跳过的设置，以后直接在对话里让 Alfred 补上。alfred doctor 说明哪一部分不正常。

服务每天检查一次新版本，核对签名和哈希之后，等手上的事做完再换上；新版本启动不了，就换回旧版本和升级前的数据。也可以随时运行 alfred update。

以前从源码装过的 Mac：换成这个安装以后，macOS 会把它当作新的程序。要连局域网里的服务，到“系统设置 > 隐私与安全性 > 本地网络”里重新打开。

版本

每个版本都附带 SHA256SUMS 和 signify 签名。装好的 Alfred 每天自己检查新版本，也可以运行 alfred update。
